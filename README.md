# 🌐 CSS Positioning & Flexbox Practice

---

## 🧭 Project Overview

This project demonstrates how different CSS positioning types (fixed, absolute, relative, and sticky) work in practice.
It also includes examples of flexbox layouts, semantic HTML5 structure, and the difference between inline and block elements like <span>, <a>, and <p>.
The project was created as part of learning how to build responsive layouts and understand modern CSS techniques using Tailwind CSS and SCSS.

---

## 🧱 Technologies Used

- **HTML5 / SCSS**

- **Tailwind CSS**

- **Vanilla JavaScript (for basic structure)**

---

## 📱 Features

- Flexbox Layout — a responsive section using flex, flex-wrap, and gap for flexible alignment.

- Relative & Absolute Positioning — demonstration of how elements can be positioned inside containers

- Tailwind Integration — shows how utility classes (like text-3xl, font-bold, underline, text-yellow-600) combine with custom SCSS styles.
